# Tally

Invoicing for small businesses: keep a list of customers, write invoices with
line items, send them, mark them paid, and see what is outstanding and overdue
on the dashboard.

Built with Next.js (App Router), Drizzle ORM on SQLite, and Tailwind CSS.

## Getting started

```bash
npm ci
npm run db:setup   # creates tally.db, applies migrations, loads sample data
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run db:setup` can be run again at any time: it replaces everything in the
database with the sample business.

## How it works

- **Customers** have a name, an email and an optional company.
- **Invoices** belong to a customer, have an issue date, a due date, notes and
  one or more line items (description, quantity, unit price). Money is stored
  as whole cents.
- An invoice is `draft`, `sent` or `paid`. Only a draft can be edited or
  deleted. A sent invoice whose due date has passed shows as **overdue**; that
  is worked out when it is shown, never stored.
- The **dashboard** shows the total outstanding (all sent invoices), what is
  overdue, and what was paid this month.

| Path                    | What it is                                  |
| ----------------------- | ------------------------------------------- |
| `db/schema.ts`          | the tables                                  |
| `drizzle/`              | migrations, generated by `npm run db:generate` |
| `db/seed.ts`            | the sample business                         |
| `lib/`                  | invoice and customer logic, and its tests   |
| `app/`                  | pages and form actions                      |

## Changing the database

Edit `db/schema.ts`, then:

```bash
npm run db:generate   # writes a new migration into drizzle/
npm run db:migrate
```
